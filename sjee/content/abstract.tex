GPU kernel throughput alone does not establish whether AES offloading benefits a system with CPU
AES-NI. We compare validated AES-128 ECB and CTR execution across three configurations, using
paired inputs, five sessions per system, and separate resident and prepared-buffer pipeline
measurements. At 32~MiB, resident GPU execution exceeds AES-NI in every session for both modes
on all systems. Pipeline results differ: CTR achieves median paired speedups of $1.354\times$ on
T600 and $4.761\times$ on T4, with gains in all five sessions, whereas GTX achieves
$0.935\times$ with only one session above parity. T4 ECB reaches $0.893\times$ and loses in
every session. The findings show that GPU offloading can outperform AES-NI, but its advantage
depends on cipher mode, workload size, host performance, and measurement scope. The pipeline
excludes preparation and application I/O; these results do not establish full application
performance.
