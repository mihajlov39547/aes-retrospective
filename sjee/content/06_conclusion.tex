\section{Conclusion}
\label{sec:conclusion}

For RQ1, the measured GPU pipeline provides consistent CTR gains over AES-NI on T600 and T4
at 32~MiB, but not on GTX; T4 ECB consistently favors the CPU. For RQ2, resident gains on all
three systems do not survive transfer inclusion uniformly. For RQ3, mode-dependent CPU
performance, non-monotonic size behavior and session variation limit generalization from a
single speedup value.

The study's contribution is a validated, reproducible comparison that preserves these
conditions and negative results. GPU offloading is a workload-dependent option rather than a
universal replacement for AES-NI. The decision must be evaluated against the actual host CPU,
data location and application boundary.
